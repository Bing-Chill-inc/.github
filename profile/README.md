# AlgoForge

## Le logiciel d'édition d'algorithmes de l'IUT de Bayonne et du Pays Basque.

Disponible sur [AlgoForge.fr](https://algoforge.fr)

## Tech Stack:

### Backend

Notre back utilise le micro-framework [Express](https://expressjs.com/) sur le runtime JavaScript [Bun](https://bun.sh/).
Nous utilisons [TypeORM](https://typeorm.io/) pour la gestion de la base de données.

### Frontend Éditeur

L'éditeur est développé en JavaScript Vanilla et utilise l'API [WebComponents](https://developer.mozilla.org/en-US/docs/Web/Web_Components) pour la création de composants réutilisables.

### Frontend Cloud

Le frontend cloud est développé en [Svelte](https://svelte.dev/).
